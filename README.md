# RSCUDrawing
The relative synonymous codon usage (RSCU) values of the protein‑coding genes in the mitochondrial genome of the target species were calculated using the RSCU analysis function in PhyloSuite v2.0 **(Zhao et al., 2025, *iMeta*, https://hub.uu2025.xyz/10.1002/imt2.70095)**. Subsequently, a combined plot illustrating amino acid usage frequency and a stacked RSCU plot was generated in R. Please note that, unlike the RSCU plots generated by PhyloSuite v2.0, the code in this repository combines Leu1 and Leu2 into a single Leu, and Ser1 and Ser2 into a single Ser. As a result, the values corresponding to all amino acids are positive integers.
